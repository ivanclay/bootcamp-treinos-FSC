# Créditos das fotos

As fotos desta pasta vêm do [Free Exercise DB](https://github.com/yuhonas/free-exercise-db), um conjunto de dados de exercícios distribuído como domínio público (licença [Unlicense](https://unlicense.org/)), derivado do [exercises.json](https://github.com/wrkout/exercises.json).

Foram convertidas para preto e branco, escurecidas e receberam uma vinheta para combinar com o layout.
