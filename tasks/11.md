# Template de Prompt para Criar uma Tool do Coach AI

Crie a tool `searchExerciseVideos` em @src/routes/ai.ts.

## Descrição

No Figma, ao perguntar como executar um exercício, o Coach AI explica a execução e os erros comuns e mostra **um vídeo** com miniatura. Hoje a IA não tem como buscar vídeos e pode inventar links.

## Requisitos Técnicos

- Use case deve se chamar "SearchExerciseVideos" (@src/usecases/SearchExerciseVideos.ts).
- Use a YouTube Data API v3 (`GET https://www.googleapis.com/youtube/v3/search`) com `part=snippet`, `type=video`, `maxResults=3`, `relevanceLanguage=pt`, `safeSearch=strict` e `q="<exercício> execução correta"`.
- A chave fica em `YOUTUBE_API_KEY` (opcional) em @src/lib/env.ts e `.env.example`.
- Se a chave não existir, o use case não chama a API e devolve só o link de busca.
- Se a API responder com erro, o use case lança `ExternalServiceError` (crie em @src/errors/index.ts). A tool trata o erro e devolve só o link de busca.
- Use Zod para validar a resposta da API do YouTube.

## Autenticação

- Mesma sessão da rota `POST /ai`.

## Input da tool

```ts
interface Input {
  exerciseName: string; // ex: "Remada Curvada"
}
```

## Output da tool

```ts
interface Output {
  videos: Array<{
    title: string;
    channelTitle: string;
    url: string; // https://www.youtube.com/watch?v=<id>
    thumbnailUrl: string;
  }>;
  searchUrl: string; // https://www.youtube.com/results?search_query=...
}
```

## Regras de Negócio

- O Coach AI **SEMPRE** chama `searchExerciseVideos` quando a pessoa pergunta como executar um exercício.
- A IA **NUNCA** inventa links: só usa `videos[].url` ou `searchUrl` retornados pela tool.
- Se `videos` vier vazio, a IA indica o `searchUrl`.
- O front-end pode renderizar o card com miniatura a partir da parte `tool-searchExerciseVideos` da mensagem.
